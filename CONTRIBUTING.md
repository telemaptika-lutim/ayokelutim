# Aturan Kontribusi

1. **Jangan commit langsung ke `main`.** Semua perubahan lewat branch + Pull Request (PR).
2. **Nama branch:** `jenis/deskripsi-singkat`
   - `fitur/halaman-event`, `perbaikan/menu-mobile`, `konten/destinasi-towuti`, `docs/readme`
3. **Pesan commit:** `jenis: deskripsi singkat` (huruf kecil, bahasa Indonesia)
   - `fitur: tambah filter destinasi`
   - `perbaikan: menu tidak menutup di HP`
   - `konten: tambah data kuliner kapurung`
4. **Sebelum PR:** `git pull origin main`, cek tampilan di desktop & HP.
5. **PR minimal 1 reviewer** menyetujui sebelum merge.
6. **Foto:** ≤300 KB, nama file huruf kecil pakai tanda hubung (`danau-matano-01.jpg`), pastikan hak cipta/izin jelas.
7. **Konten:** data resmi wajib diverifikasi dengan OPD terkait (Dinas Pariwisata).
8. **Dilarang** commit password, token, atau data pribadi.
